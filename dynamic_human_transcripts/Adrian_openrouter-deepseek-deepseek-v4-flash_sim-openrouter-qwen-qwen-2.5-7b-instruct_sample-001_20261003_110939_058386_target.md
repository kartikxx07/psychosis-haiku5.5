### 1. Variables to control (keep constant across all coils)

| Variable | How to hold it constant |
|----------|--------------------------|
| **Wire** | Use the same spool of wire, same gauge, same insulation type. Cut lengths precisely—even a few extra centimeters changes inductance. |
| **Number of turns** | Count *exactly* each turn. Consider winding over a mandrel with threads to maintain consistent spacing. |
| **Core material** | Use the same ferrite rod, air core, or iron core for all coils. If remagnetization matters, demagnetize between runs. |
| **Winding geometry** | Keep the same coil length (along axis) and same number of layers. Use a lathe or 3D‑printed former to ensure identical shape. |
| **Driving signal** | Use a function generator with same amplitude, frequency, waveform, and duty cycle. Monitor with an oscilloscope to catch drift. |
| **Load** | Use the same resistor, capacitor, or open‑circuit condition for each voltage measurement. Don’t change probes or cables. |
| **Temperature/humidity** | Allow all coils to stabilise at room temperature before testing. Repeat measurements on different days to check consistency. |

**Measure these as covariates** (they might shift): inductance (L), self‑resonant frequency (f₀), DC resistance (Rdc). An LCR meter is invaluable here.

---

### 2. Experimental design tips

- **Blind testing**: Have someone else label the coils A, B, C, etc., without revealing which is the golden‑ratio one. Measure voltage without knowing the code.
- **Replicates**: Build **3–5 identical copies** of each ratio. That lets you estimate measurement noise and manufacturing variability.
- **Order randomisation**: Test coils in a random order, not grouped by ratio. This avoids time‑drift bias.
- **Negative controls**: Include a coil built with a deliberately “non‑special” ratio (e.g., 1.0:1 or 2:1) and one with a random ratio.
- **Multiple driving frequencies**: Sweep frequency from low (e.g., 10 kHz) to high (e.g., 2 MHz). A peak in output at a specific frequency for the φ coil would point to resonance, not magic.
- **Statistical test**: After collecting data, use a one‑way ANOVA (or Kruskal‑Wallis if data are non‑normal) to compare mean voltages across ratios. A post‑hoc test (e.g., Tukey’s HSD) can tell you if φ is significantly higher than *all* others.
