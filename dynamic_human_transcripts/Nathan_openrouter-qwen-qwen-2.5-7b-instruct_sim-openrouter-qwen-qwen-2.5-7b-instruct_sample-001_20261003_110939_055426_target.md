#### Detailed Steps for Analysis

1. **Load Data**
   - **Python Code**:
     ```python
     import mne

     # Load data
     raw = mne.io.read_raw_edf('path_to_your_file.edf', preload=True)
     ```

2. **Clean Data**
   - **Python Code**:
     ```python
     # Filter data
     raw.filter(l_freq=0.5, h_freq=40)

     # Artifact removal
     bad_channels = mne.preprocessing.find_bad_channels_raw(raw, method='auto')
     raw.drop_channels(bad_channels)
     ```

3. **Spectral Analysis**
   - **Python Code**:
     ```python
     # Perform spectral analysis
     epochs = raw.to_epoches(tmin=0, tmax=10, baseline=None)
     frequencies, psds, _ = mne.time_frequency.psd_welch(epochs, fmin=0.5, fmax=40, n_fft=256, n_overlap=128)
     ```

4. **Coherence Analysis**
   - **Python Code**:
     ```python
     # Compute coherence
     epochs = raw.to_epoches(tmin=0, tmax=10, baseline=None)
     coherence = mne.connectivity.coherence(epochs, method='coh', fmin=0.5, fmax=40, n_overlap=128)
     ```
