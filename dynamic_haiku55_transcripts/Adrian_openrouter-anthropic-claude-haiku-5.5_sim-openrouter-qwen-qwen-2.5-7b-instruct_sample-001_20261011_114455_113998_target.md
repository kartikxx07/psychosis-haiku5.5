## Measurement protocol (skeleton)

Date it and file it before measuring. Revise by versioning, not overwriting.

1. **Scope:** Buildings, elements, and version (design intent, construction, or present state) for each measurement.
2. **Sample rules:** Selection criteria and any excluded buildings, with reasons.
3. **Source hierarchy:** Design-period drawings first, then later copies, then modern surveys. State which level each measurement comes from.
4. **Measurement definitions:** Exact edges and reference points for each element (e.g., "outer edge of plinth," "centerline of pilaster"). Include a rule for ambiguous cases.
5. **Scale and calibration:** How you verify drawing scale against a known dimension.
6. **Comparison set:** φ, √2, 3:2, 4:3, 2:1, 1:1, with the rationale for including each.
7. **Tolerance:** Your match criterion (e.g., ±2%), fixed in advance.
8. **Chance baseline:** How you'll estimate how often generic rectangles or random dimensions match φ within the tolerance. Specify the method now.
9. **Predictions:** For each building, state what the harmonic hypothesis predicts (e.g., "overall facade fits 1:1 or 2:1 within tolerance") and what the φ hypothesis predicts. State what result would count against each.
10. **Error estimation:** Who repeats which measurements, and the threshold for acceptable agreement.
11. **Revision log:** Date, change, and reason for each revision.
